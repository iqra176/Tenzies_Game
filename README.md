# 🎲 Tenzies Game

A fun and interactive dice game built with React. Roll the dice, hold matching numbers, and try to get all dice to show the same value.

## ✨ Features

* 🎲 Roll multiple dice
* ✋ Hold individual dice
* 🏆 Win when all dice show the same number
* 🔄 Start a new game
* ⚡ Interactive React interface
* 📱 Responsive design

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Vite
* Git & GitHub

## 🎮 How to Play

1. Click **Roll** to roll the dice.
2. Click any die to **hold** its current value.
3. Roll again and continue holding matching dice.
4. Keep playing until **all dice show the same number**.
5. 🎉 You win!

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/iqra176/Tenzies_Game.git
```

Go to the project folder:

```bash
cd Tenzies_Game
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.
